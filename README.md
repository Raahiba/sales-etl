# ETL Pipeline using PySpark and Databricks
A data engineering project that implements an **ETL pipeline using PySpark** to process e-commerce data from Kaggle. The pipeline extracts raw CSV data, performs data cleaning and transformations, and loads the processed data into **Delta Lake**.

## Project Overview

The objective of this project is to build a modular ETL pipeline for processing e-commerce datasets using PySpark.
The pipeline follows three main stages:
**Extract → Transform → Load**
Raw datasets are extracted from CSV files, transformed using PySpark, and stored as Delta Lake data for further analysis and downstream processing.
